# 八种动效的实现参考

这里将视频中的设计原则转为平台无关的实现建议。公式和阈值是可调整模型，不是对原作者源码的复原。只读取任务涉及的章节。

## 1. 磁吸交互 / Magnetic Snap

**视频原则：** 先阻力，后贴合；距离越近，吸力越强。

- 输入：拖动对象与候选吸附点的距离、方向和速度。
- 映射：设置有界影响半径 `r`，以 `w = clamp(1 - d/r, 0, 1)` 表达接近程度；可用 `w*w` 得到非线性吸附权重。将权重用于受控的吸引偏移或弹簧目标。
- 接近时给出轻微阻力或粘滞感，满足条件后吸附到明确目标；不使用全程匀速平移冒充磁吸。
- 设置不同的进入和脱离距离，避免在边界抖动。允许用户拖离目标，不让吸附永久锁死操作。
- 检查：远处自由移动、近处反馈增强、可脱离、最终无抖动。多个目标竞争时保持选择稳定。

## 2. 液态形变 / Liquid Morph

**视频原则：** 形变跟着运动状态走，运动越快形变越明显，停下时恢复。

- 用平滑后的速度幅值控制拉伸量，沿运动方向拉伸，垂直方向适度压缩。
- 可用 `s = 1 + clamp(k * abs(v), 0, stretchMax)`，另一轴用 `1/s` 作为近似保面积模型；按实际对象形状限制变形。
- 方向变化时平滑转换形变轴，避免噪声导致左右抽动。松手后弹性恢复到单位缩放。
- 对文字密集卡片优先减少形变量，或仅改变外壳/背景，避免文字明显失真。
- 检查：慢拖变形小、快拖变形大，停止恢复；不是与手势无关的固定循环抖动。

## 3. 3D 视差 / 3D Parallax

**视频原则：** 层级差形成空间感，不同深度应有不同移动幅度或速度。

- 将背景、图片、文字分层，由同一个归一化指针或拖动输入驱动。
- 可从背景 `0.2×`、图片 `0.6×`、前层文字 `1.0×` 的相对幅度起步；这是视频示例比例，按可读性和空间大小调整。
- 如使用倾斜，围绕一致的视觉中心设置小角度变化；3D 旋转不是必要条件。
- 限制位移，给裁切边缘留余量，退出交互后平滑归位。
- 检查：层间存在清晰但克制的差异，背景不露白，前景文字保持可读。

## 4. 滚动聚焦 / Scroll Focus

**视频原则：** 越靠近中心越突出，用动效建立当前内容的视觉焦点。

- 以项目中心与容器焦点的距离驱动权重：`w = clamp(1 - abs(itemCenter - focus)/radius, 0, 1)`。
- 通过有界的缩放、透明度或层级增强焦点；远处内容仍保持可辨认和可操作。
- 不对每个项目独立播放固定动画，让变化连续响应滚动位置。需要吸附时，在手势和惯性收尾阶段自然停靠。
- 焦点可以是设计指定位置，不强制为整屏正中。缩放尽量不改变列表布局尺寸，避免测量和滚动互相影响。
- 检查：焦点随滚动连续转移，边缘项目不被遮挡，首尾项目可以到达。

## 5. 流体 Tab / Fluid Tab

**视频原则：** 前沿快、后沿慢，两侧进度差形成拉伸，再收缩贴合。

- 分别控制指示器左右边界，而不只是平移固定宽度的矩形。
- 向右切换时右边为前沿，向左切换时左边为前沿。前沿更快靠近目标，后沿随后追上。
- 视频展示 `lead 0.20 / tail 0.105`，可理解为演示中的响应差，不是秒数或通用弹簧常数。
- 若采用指数追随，用 `alpha = 1 - exp(-lambda * dt)`；前沿 `lambda` 更大。动态测量目标标签边界，支持不同宽度。
- 保证左右边界有序、最小宽度有效，最终准确包住新标签。连续点击时从当前两侧位置重定向。
- 检查：左右方向都成立，跨多个标签切换及快速反向不会翻转、越界或闪跳；选中语义及时更新。

## 6. 图片展开 / Image Expand

**视频原则：** 同一张图片由局部展开到全屏，变化的是容器和裁切范围。

- 测量缩略图在视口中的实际矩形，确定大图目标矩形、图片比例及裁切策略。
- 建立共享元素或叠加层，使其起始位置、尺寸、圆角和可见内容与缩略图一致，再过渡到目标。
- 可用 FLIP：记录初始和最终几何，施加逆变换对齐初始，再释放变换；也可用平台已有共享元素转场。
- 避免简单拉伸导致图片变形。需要从 cover 变到 contain 时，单独处理图片内容和裁切窗口，保持主体连续。
- 返回时重新测量有效源位置；源项消失时平滑降级。图片加载、滚动偏移、关闭操作和焦点恢复纳入生命周期。
- 检查：开合均无换图闪烁、重复影像或终点跳变，滚动后的源位置仍正确。

## 7. 手势驱动转场 / Gesture Drive

**视频原则：** 指尖位置就是动画进度，用户可以前进也可以回退。

- 拖动时使用 `progress = clamp(direction * displacement / travel, 0, 1)`，并从当前进度记录新的拖动起点。`travel` 为有效行程，须大于零。
- 让位移、缩放、背景或遮罩共享该进度，不在拖动期间启动与输入无关的自动播放动画。
- 松手后根据进度阈值和方向速度决定完成或回退。阈值可调，不把截图中模糊数值写成规范。
- 状态明确区分空闲、拖动、完成收尾和取消收尾；新手势可以接管当前动画。
- 处理系统取消、指针丢失以及横向切换与纵向滚动的竞争。
- 检查：慢拖、反拖、快速甩动、未达阈值松手、中途取消均能回到一致的有效页面状态。

## 8. 物理碰撞 / Physics Bounce

**视频原则：** 多个元素遵循同一套物理规则，质量不同使推挤和回弹结果不同。

- 对元素明确位置、速度、质量和碰撞边界，共用一致的时间步、阻尼、恢复系数及边界规则。
- 轻元素受到相同冲量时速度改变更大，重元素改变更小；不靠给每张卡片手写随机关键帧伪造相互作用。
- 如需冲量模型，定义法线 `n` 从 A 指向 B，`relativeNormal = dot(vB-vA, n)`；仅在小于零、相互接近时计算 `j = -(1+e)*relativeNormal/(invMassA+invMassB)`，并分别对 A 减、B 加对应冲量。分母为零时跳过。
- 使用有界时间步、必要的子步与重叠修正，防止低帧率穿透、持续抖动或能量异常增加。
- 视频示例质量比为 `1.0 : 0.55 : 1.6`，仅用于说明轻重差异。普通按钮反馈无需引入完整物理引擎。
- 检查：相碰才产生相应推挤，静止后稳定，不穿透容器，不妨碍内容点击和阅读。
